# 새 글 올리는 법

구 홈페이지(tjpark.postech.ac.kr) 게시판은 더 이상 쓰지 않습니다.
새 글은 이 폴더의 파일에 항목을 하나 더하면 됩니다.
**GitHub 웹에서 고치고 저장하면, 몇 분 뒤 홈페이지에 저절로 올라갑니다.**

| 무엇을 올리나 | 어느 파일 |
|---|---|
| 공지사항 · 보도자료 및 신문기사 | `posts.json` |
| 연구총서 등 새로 나온 책 | `books.json` |
| 언론자료(박태준 관련 기사) | `media_links.json` |
| 영상 | `videos.json` |

---

## 공지사항 올리기

1. GitHub에서 `data/curated/posts.json` 파일을 엽니다.
2. 연필 모양(Edit) 단추를 누릅니다.
3. 맨 위 `[` 바로 아래에 아래 덩어리를 붙여 넣고 내용을 고칩니다.
4. 아래 **Commit changes** 를 누릅니다. 끝입니다.

```json
  {
    "board": "news_notice",
    "date": "2026-09-10",
    "title": "제6회 미래전략 포럼 개최 안내",
    "body": [
      "첫 문단입니다. 한 문단을 따옴표로 감싸 한 줄씩 적습니다.",
      "둘째 문단입니다. 줄 끝에 쉼표를 찍고, 마지막 문단에는 찍지 않습니다."
    ]
  },
```

**꼭 지킬 것 세 가지**

- 항목과 항목 사이는 쉼표(`,`)로 잇고, **맨 마지막 항목 뒤에는 쉼표를 찍지 않습니다.**
- 따옴표는 반드시 곧은 따옴표(`"`)를 씁니다. 워드에서 복사하면 둥근 따옴표(`“ ”`)가 딸려 오니 주의해 주세요.
- 본문 안에 큰따옴표를 쓰고 싶으면 작은따옴표(`'`)나 낫표(`「 」`)로 바꿔 주세요.

날짜만 맞으면 목록에서 자리를 알아서 찾아갑니다. 최신 글이 맨 위로 갑니다.

## 보도자료 올리기

`"board"` 를 `"news_press"` 로 바꾸고, 매체 이름을 넣습니다.

```json
  {
    "board": "news_press",
    "date": "2026-09-10",
    "outlet": "경북일보",
    "title": "포스텍 박태준미래전략연구소, 미래전략 포럼 열어",
    "body": [
      "기사 본문 또는 요약을 문단별로 적습니다."
    ],
    "link": "https://www.kyongbuk.co.kr/news/articleView.html?idxno=0000000"
  },
```

`"link"` 를 넣으면 글 아래에 **원문 보기** 단추가 붙습니다. 기사 전문을 그대로
옮길 때는 저작권을 확인해 주세요.

## 연혁에 한 줄 더하기

연혁 페이지(`about/history.html`, `en/about/history.html`)는 2024년까지가 구
홈페이지에서 옮겨 온 기록이고, 그 뒤로는 **`history.json`** 에 적은 것이
이어 붙습니다. 한글과 영문 페이지가 이 한 파일을 같이 씁니다.

`data/curated/history.json` 을 열어 연도 덩어리 안에 한 줄을 더합니다.

```json
{
 "year": "2026",
 "items": [
  {
   "date": "09.10",
   "ko": "제8회 박태준미래전략연구 포럼 개최",
   "en": "Eighth TJ Park Future Strategy Forum held"
  }
 ]
}
```

- `date` 는 **월.일을 두 자리씩** (`09.10`). 페이지에는 `9.10` 으로 나옵니다.
- `ko` 와 `en` 을 **둘 다** 적습니다. 영문을 비우면 영문 연혁에서 그 줄만
  빠져 두 페이지가 어긋납니다.
- 없는 연도를 새로 시작할 때는 덩어리째 만들고, **연도는 오름차순**으로
  둡니다. 같은 연도를 두 번 만들지 마세요.
- 책 제목은 한글은 겹낫표 `『 』`, 영문은 `*Becoming MIT*` 처럼 별표로
  감쌉니다(영문 페이지에서 이탤릭이 됩니다).

총서가 새로 나왔다면 보통 세 군데를 같이 손봅니다 — `books.json`(연구총서
페이지), `posts.json`(발간 공지), `history.json`(연혁).

## 첫 화면 카드뉴스 바꾸기

첫 화면 오른쪽의 **TJPI 카드뉴스** 칸은 `data/curated/cardnews.json` 하나로
만들어집니다. 한글·영문 첫 화면이 같은 파일을 봅니다.

```json
{
 "tag":   {"ko": "TJPI 카드뉴스", "en": "TJPI CARD NEWS"},
 "title": {"ko": "머리글 한 줄", "en": "Headline"},
 "lead":  {"ko": "소개 한 문장.", "en": "One sentence."},
 "books": [
  {
   "href":  "research/books/100015.html",
   "cover": "assets/img/books/9791191383690.jpg",
   "label": {"ko": "미래전략연구총서 15", "en": "Vol. 15"},
   "title": {"ko": "MIT가 MIT가 되기까지", "en": "Becoming MIT"}
  }
 ],
 "more": {"href": "research/books.html",
          "ko": "연구총서 전체 보기", "en": "All volumes"}
}
```

- `href` 는 연구총서 목록에서 그 책을 눌렀을 때 주소창 뒤에 붙는 부분을
  그대로 적습니다. `cover` 는 그 책 페이지에 쓰인 표지 파일 경로입니다.
- 책은 **두 권**이 알맞습니다. 칸이 좁아 세 권을 넘기면 표지가 작아집니다.
- 영문 `title` 을 비우면 한글 제목이 그대로 실립니다. 번역서라면 원서 제목을
  적어 두는 편이 읽기 좋습니다.
- 머리글(`title`)과 실린 책이 따로 놀지 않게, 책을 바꿀 때 문안도 같이
  손봅니다. 이 칸은 게시판에서 자동으로 끌어오지 않는 유일한 자리입니다.

## 사진과 첨부파일

먼저 파일을 저장소에 올려야 합니다. GitHub에서 아래 폴더로 들어가
**Add file → Upload files** 로 올린 뒤, 그 경로를 적습니다.

- 사진 → `assets/img/news/`
- 첨부 → `assets/files/news_notice/`

```json
  {
    "board": "news_notice",
    "date": "2026-09-10",
    "title": "제6회 미래전략 포럼 개최 안내",
    "body": ["…"],
    "images": ["assets/img/news/2026-forum.jpg"],
    "files": [
      { "name": "제6회 포럼 일정.pdf", "path": "assets/files/news_notice/2026-forum.pdf" }
    ]
  },
```

사진은 첫 장이 목록 카드에 쓰이고, 나머지는 글 아래에 이어 붙습니다.

## 넣을 수 있는 항목 전체

| 이름 | 필요 | 설명 |
|---|---|---|
| `board` | 필수 | `news_notice`(공지) 또는 `news_press`(보도자료) |
| `date` | 필수 | `2026-09-10` 꼴. 글 번호와 목록 차례가 이 날짜에서 정해집니다 |
| `title` | 필수 | 제목 |
| `body` | 필수 | 문단 목록 |
| `outlet` | 선택 | 매체 이름(보도자료) |
| `author` | 선택 | 기자·작성자 |
| `summary` | 선택 | 목록에 보일 한 줄. 없으면 첫 문단 앞부분을 씁니다 |
| `link` | 선택 | 원문 주소 |
| `link_note` | 선택 | 원문 주소에 덧붙일 설명 |
| `images` | 선택 | 사진 경로 목록 |
| `files` | 선택 | 첨부 목록 (`name`, `path`) |
| `id` | 선택 | 글 번호를 직접 정하고 싶을 때만. 보통은 비워 둡니다 |

## 잘못 적으면 어떻게 되나요

쉼표나 따옴표가 틀리면 홈페이지가 **바뀌지 않고 그대로 남습니다.** 망가지지
않으니 안심하셔도 됩니다. GitHub의 **Actions** 탭에 빨간 X 표시가 뜨는데,
그것을 눌러 보면 몇 번째 줄이 틀렸는지 알려 줍니다. 고쳐서 다시 저장하면 됩니다.

올린 뒤 3~5분쯤 지나 홈페이지를 새로 고쳐 보시면 반영돼 있습니다.
